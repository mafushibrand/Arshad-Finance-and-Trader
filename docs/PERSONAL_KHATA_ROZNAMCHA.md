# Personal Khata Roznamcha

The build workflow applies `scripts/apply-personal-khata-roznamcha.py` to the Android source archive. It adds a dedicated Roznamcha tab inside Personal Khata, date filters (today/month/all), cash-in and cash-out summaries, dated entries with descriptions, and regression tests. Entries are stored as `PERSONAL_ROZNAMCHA` records separately from customer ledger balances.
